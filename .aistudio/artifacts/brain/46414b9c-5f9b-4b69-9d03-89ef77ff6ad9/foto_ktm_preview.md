### Cara Menggunakan Foto Asli Ini 100% Tanpa Perubahan Wajah:
Di website portofolio pada bagian foto utama di Hero Section, telah disediakan tombol **"Ganti dengan File Asli (Foto KTM.jpeg)"**. Anda cukup mengklik tombol tersebut dan memilih file `Foto KTM.jpeg` dari komputer/HP Anda. Foto akan langsung tampil dengan resolusi penuh 100% dan tersimpan otomatis di browser tanpa perubahan apapun pada struktur wajah.
